## 1. المرتكزات المالية الصارمة (Zero Financial Liability Axioms)

يلتزم نظام **OmniFlow OS** في نسخته الشخصية المحلية بنموذج تشغيل مجاني بالكامل بنسبة 100%:
1. **لا بطاقات بنكية (Zero Credit Card):** لا يتطلب تشغيل النظام أي بطاقة دفع أو فتح حساب فوترة سحابي (Cloud Billing).
2. **لا فترات تجريبية مؤقتة (No Free Trials):** لا يعتمد النظام على أي عروض تجريبية مجانية تنتهي بالدفع أو التحويل لخطط مدفوعة.
3. **لا اشتراكات شهرية:** لا توجد أي التزامات مالية دورية.
4. **تعطيل الخدمات السحابية المدفوعة تلقائياً:** يتم حجب أو محاكاة أي مزود خارجي يتطلب تسعيرًا بالاستهلاك (Pay-as-you-go).

## 2. سياسة الشبكة والعزل السحابي (Local-Only Network Binding)

* **عنوان الربط الافتراضي (Host Binding):**
  يتم ربط خادم Express 4 محليًا وحصريًا على:
  ```text
  127.0.0.1 (Loopback Interface Only)
  ```
* **حظر التعرض لشبكة الـ LAN بدون إذن:**
  الربط على `0.0.0.0` محظور افتراضيًا لمنع فتح الخادم على الشبكة المحلية أو تعريضه لأي أجهزة خارجية، إلا إذا قام المستخدم صراحة بتفعيل متغير البيئة `HOST=0.0.0.0` عن قصد.
* **حظر الأنفاق التلقائية (No Automatic Tunneling):**
  يُمنع استخدام أدوات مثل `ngrok` أو التوجيه التلقائي للمنافذ (UPnP) دون تدخل يدوي من المالك.

## 3. محاكاة التكاملات الخارجية في وضع التكلفة صفر (Simulation Sandbox)

نظراً لأن القنوات والاتصالات الحقيقية تتطلب فواتير أو اشتراكات خارجية، فقد تم اعتماد نموذج **Sandbox Simulation** الصريح:

### A. الاتصالات الهاتفية (Voice & Telephony Sandbox)
* **الواقع الحقيقي:** خطوط SIP Trunks وشبكات الـ PSTN وخدمات Twilio/FreeSWITCH تتطلب أرقاماً مدفوعة واشتراكات دورية.
* **الحل المحلي:** يوفر النظام محاكي اتصالات صوتية محلي بالكامل (`Simulation Sandbox`) يولد جلسات اتصال وسجلات وتفريغ نصوص وتحليلات مشاعر داخل الذاكرة وقاعدة البيانات المحلية، لاختبار دورة حياة المكالمة كاملة بدون أي تكلفة اتصالات.
* **الشفافية في الواجهة:** يتم وضع علامة `[وضع المحاكاة المحلي - Sandbox]` على المكالمات لتوضيح أنها محاكاة تشغيلية.

### B. تكامل الواتساب (WhatsApp Business Cloud API)
* **الواقع الحقيقي:** استخدام WhatsApp Cloud API المباشر من Meta يفرض رسومًا بعد المحادثات المجانية الأولى ويتطلب حساب Meta Business وربط وسيلة دفع.
* **الحل المحلي:** استقبال رسائل الويب هوك وتوليد الردود يتم اختبارهما عبر محاكي محلي مع حماية التوقيع الداخلي، دون إجراء أي اتصال خارجي بخوادم Meta Graph API ودون إرسال رسائل فعلية خارجية تستهلك رصيداً.

### C. نماذج الذكاء الاصطناعي (AI Gateway Zero-Cost Route)
* **الواقع الحقيقي:** نماذج الاستدلال السحابية (Gemini Pro/Claude/OpenAI) تتطلب مفاتيح واشتراكات مدفوعة بالتوكن عند انتهاء الحصص.
* **الحل المحلي:**
  1. الوضع الأساسي الافتراضي هو **محرك القواعد اللغوية المحلية السريعة (Local Heuristic NLP)** الذي يعمل بزمن استجابة أقل من 20 مللي ثانية وتكلفة **0.00$ مطلقة** دون أي خروج للبيانات (Zero Egress).
  2. دعم ربط **Ollama** محليًا لتشغيل نماذج مفتوحة المصدر (مثل Qwen 2.5 Coder أو Llama 3) على معالج الجهاز المحلي دون أي تكلفة سحابية.
